# 💾 Flash Trash Sorter

> Локальный веб-инструмент для быстрой сортировки файлов, чистки старых флешек и наведения порядка в залежах «Новая папка (2)» без забивания системного диска. А еще тут есть костыльная медиа-панель, потому что на урезанных клавиатурах вечно нет нормальных клавиш громкости.

---

## ✨ Основные фичи

- **⚡ Умная категоризация в один клик**: Раскидывай файлы и папки по категориям (`Игры`, `Steam`, `Репаки`, `Проекты`, `Софт`, `Прошивки`, `Образы`, `Бэкапы`, `Музыка`, `Видео`, `Документы`, `Фото`, `Неизвестно`, `Мусор`)[cite: 6].
- **🔄 Каскадная сортировка**: При выборе категории для папки она автоматически применяется ко всем её вложенным элементам.
- **⌨️ Медиа-панель для урезанных клав**: Управляй треками (Next, Prev, Play/Pause) и звуком (Громче, Тихо, Mute) прямо из браузера через эмуляцию системных клавиш Windows[cite: 6].
- **🎨 Кастомные темы**: Переключайся между стилями прямо на лету (Тёмный слейт, Киберпанк, Матрица, Закат, Монохром, Зимний вайб)[cite: 6].
- **💾 Умный отчёт и экспорт**: Сохраняй итоговую структуру в аккуратный текстовый файл (`otchet_sortirovki.txt`) в корень проекта[cite: 6].

---

## 🚀 Быстрый старт (для ленивых)

Тебе понадобится только установленный Python.

1. Скачай или клонируй этот репозиторий[cite: 6].
2. Дважды кликни по файлу **`run.bat`**[cite: 6]. 
   > Скрипт сам проверит библиотеки, установит `FastAPI`, `Uvicorn` и `Pydantic`, автоматически найдёт свободный порт, запустит сервер и откроет нужную вкладку в браузере[cite: 6].

---

## 🛠️ Запуск вручную (через терминал)

```bash
# 1. Установи зависимости
pip install fastapi uvicorn pydantic

# 2. Запусти бэкенд (скрипт сам подберет свободный порт, если 8000 занят)
python main.py

# 3. Или запусти с указанием конкретного порта
python main.py 8080
