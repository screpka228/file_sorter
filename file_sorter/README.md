# 💾 Flash Trash Sorter

> Локальный веб-инструмент для быстрой сортировки файлов, чистки старых флешек и наведения порядка в залежах «Новая папка (2)» без забивания системного диска. А еще тут есть костыльная медиа-панель, потому что на 70% клавиатурах вечно нет нормальных клавиш громкости.

---

## ✨ Основные фичи

- **⚡ Умная категоризация в один клик**: Раскидывай файлы и папки по категориям (`Игры`, `Steam`, `Репаки`, `Софт`, `Прошивки`, `Мусор` и священная категория `ХЗ / Не ебу что это`).
- **⌨️ Медиа-панель для урезанных клав**: Управляй треками (Next, Prev, Play/Pause) и звуком (Громче, Тихо, Mute) прямо из браузера через эмуляцию системных клавиш Windows.
- **🎨 Темы оформления**: Переключайся между классическим слейтом, вырвиглазным киберпанком и матричным зелёным стилем («теамэки»).
- 💾 Экспорт результатов: Сохраняй итоговый план сортировки в аккуратный `.txt` файл одним нажатием.

---

## 🚀 Быстрый старт (для ленивых)

Тебе понадобится только установленный Python.

1. Скачай или клонируй этот репозиторий.
2. Дважды кликни по файлу `run.bat`. 
   > Скрипт сам проверит библиотеки, установит `FastAPI` и `Uvicorn`, запустит сервер и автоматически откроет вкладку в браузере (`http://127.0.0.1:8000`).

---

# 2. Запусти бэкенд
